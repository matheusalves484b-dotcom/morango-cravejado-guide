# Morango Cravejado Guide

Crie um ebook digital premium em português do Brasil chamado:

“MORANGO CRAVEJADO”
“O guia completo para preparar, precificar e vender o doce que virou tendência”

IMPORTANTE:
Este projeto NÃO deve parecer um site empresarial, dashboard ou landing page.
Ele deve parecer um ebook profissional de confeitaria/gastronomia, com estética editorial premium, sofisticada e comercial.

OBJETIVO:
Criar uma experiência de ebook digital com aproximadamente 30–40 páginas/seções, preparada para leitura no computador e celular e também para exportação/impressão em PDF no formato A4 vertical.

O conteúdo deve ensinar tanto a produção do Morango Cravejado quanto a parte comercial: custos, precificação, embalagem, marketing e vendas.

IDENTIDADE VISUAL
==================================================

Criar uma identidade visual gourmet, elegante, feminina, sofisticada e contemporânea.

Paleta principal:

Roxo ameixa: #6B245F

Rosa framboesa: #C83E70

Creme: #FFF8F2

Dourado: #C89B3C

Chocolate escuro: #2C1D2A

Branco: #FFFFFF

Distribuição visual aproximada:

70% creme/branco
20% roxo
7% rosa
3% dourado

Não utilizar excesso de roxo ou rosa.

O dourado deve aparecer apenas como detalhe de luxo:
linhas finas, pequenos elementos, números, divisórias e destaques.
